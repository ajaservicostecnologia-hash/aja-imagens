# AJA — imagens de produto

Imagens de produto do fornecedor, preparadas para as regras de imagem da Amazon US
(JPEG RGB, lado maior >= 1.000 px). Servidas por GitHub Pages porque a Listings API da
Amazon busca a imagem por URL publica e nao aceita upload.

Geradas por `publicador/imagens_us.py` do projeto RENDA EURO.
